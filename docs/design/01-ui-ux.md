# UI/UX 설계

Termius의 정보 구조(홈 화면의 호스트 카드, 왼쪽 메뉴, 검색 우선 연결, 별도 SFTP 탭)를 기본 틀로 삼습니다. 여기에 MyTerminal의 차별화 기능인 터미널 옆 SFTP 패널, 원격 파일 편집, AI 추천을 더합니다.

> **참고 범위:** 화면 구성과 사용 흐름만 참고합니다. Termius의 이름, 로고, 아이콘, 색상, 고유한 그래픽은 가져오지 않습니다. 아이콘은 SF Symbols를, 색상은 자체 팔레트를 씁니다. 오픈소스로 공개할 프로젝트이므로 지켜야 하는 원칙입니다.

## 설계 원칙

1. **검색 우선**: 홈 화면의 첫 요소는 검색창입니다. 호스트 이름이나 `ssh user@host`를 입력하고 Enter를 누르면 바로 연결됩니다.
2. **카드로 한눈에**: 호스트는 OS 아이콘, 이름, 접속 정보를 담은 카드로 보여 줍니다.
3. **키보드로 모든 것**: ⌘K(명령 팔레트·AI), ⌘T(새 탭), ⌘D(분할), ⌘1~9(탭 이동)
4. **다크 테마 기본**: 라이트 테마도 지원하되 기본은 다크입니다.
5. **작업 맥락 유지**: 지금 어떤 작업 중인지 항상 화면에 보이고, 명령이 그 작업에 기록됩니다.

## 화면 구성

### 1) 홈 화면 (호스트)

```text
┌─[● ● ●]─[⌂ 홈]─[📁 SFTP]─[web-01 ×]─[+]─────────────────────────────────────── ┐
│ ┌──────────────┐ ┌───────────────────────────────────────────────────────────────┐ │
│ │ ▣ 호스트      │ │ 🔍 호스트 검색 또는 ssh user@hostname...          [ 연결 ] │ │
│ │ ◷ 히스토리    │ └───────────────────────────────────────────────────────────────┘ │
│ │              │  [+ 새 호스트]  [가져오기·내보내기]  [>_ 로컬 터미널]        [정렬] │
│ │              │                                                                   │
│ │              │  운영 서버                                                        │
│ │              │  ┌────────────────────┐ ┌────────────────────┐ ┌────────────────┐ │
│ │              │  │ [🐧] web-01         │ │ [🐧] was-01         │ │ [🐧] db-01      │ │
│ │              │  │      ssh, deploy    │ │      ssh, deploy    │ │      ssh, admin │ │
│ │              │  └────────────────────┘ └────────────────────┘ └────────────────┘ │
│ │              │  개발 / 개인                                                       │
│ │              │  ┌────────────────────┐ ┌────────────────────┐                    │
│ │ ⚙ 설정       │  │ [] mac-mini       │ │ [🐧] staging-web    │                    │
│ └──────────────┘  └────────────────────┘ └────────────────────┘                    │
└────────────────────────────────────────────────────────────────────────────────────┘
```

- **위쪽 탭 바**: 홈, SFTP, 열린 터미널 탭이 한 줄에 놓입니다. 터미널 탭에서는 오른쪽에 SFTP(파일 패널) 버튼이 있습니다.
- **왼쪽 메뉴**: 호스트 · 히스토리(접속 이력) · 설정
- **호스트 카드**
  - OS 아이콘(첫 접속 때 자동 감지), 이름, `ssh, 사용자`를 표시합니다.
  - 그룹별로 묶고, 태그 색을 표시합니다.
  - 더블클릭하면 새 탭에서 접속합니다.
  - 마우스를 올리면 빠른 버튼이 나타납니다: SFTP 열기, 분할로 열기, 편집
  - 오른쪽 클릭 메뉴: 복제, 삭제, 연결 명령 복사
- **보기 전환**: 카드(그리드)와 목록(테이블) 중 고를 수 있습니다.

### 1-1) 호스트 편집 패널 (오른쪽에 밀려 나옴) — 구현됨

```text
┌─ 호스트 카드 목록 ───────────────────────────┐┌─ 호스트 정보  저장됨      … →| ┐
│ ┌──────────────────┐ ┏━━━━━━━━━━━━━━━━━━━━┓  ││ ┌ 주소 ───────────────────────┐ │
│ │ [🖥] web-01       │ ┃ [🖥] db-01      [✎] ┃  ││ │ [🖥] [ 10.0.0.5            ] │ │
│ │      ssh, deploy │ ┃      ssh, admin    ┃  ││ └─────────────────────────────┘ │
│ └──────────────────┘ ┗━━━━━━━━━━━━━━━━━━━━┛  ││ ┌ 일반 ───────────────────────┐ │
│                      (선택: 파란 테두리)       ││ │ 이름 · 그룹 ▾ · 태그          │ │
│                                              ││ └─────────────────────────────┘ │
│                                              ││ ┌ SSH ────────────────────────┐ │
│                                              ││ │ 사용자 · 포트                 │ │
│                                              ││ │ [키 · 에이전트 | 비밀번호]    │ │
│                                              ││ │ 키 파일 / 비밀번호 · 점프 호스트│ │
│                                              ││ └─────────────────────────────┘ │
│                                              ││ ┌ 메모 ───────────────────────┐ │
│                                              ││ [            연결            ] │
└──────────────────────────────────────────────┘└───────────────────────────────┘
```

- 카드: 클릭 = 선택, 연필 = 패널 열기, 더블클릭 = 연결
- 패널이 열린 채 다른 카드를 클릭하면 패널 내용이 바뀐다
- 기존 호스트는 자동 저장, 새 호스트는 "추가" 버튼

### 2) 터미널 탭

```text
┌─[⌂ 홈]─[📁 SFTP]─[web-01 ×]─[was-01 ×]─[+]─────────────────────────── [SFTP] ┐
│ ┌───────────────────────────────┬──────────────────────┐ ┌────────────────────┐ │
│ │ deploy@web-01:~$ ...           │ deploy@was-01:~$ ... │ │ 파일 (SFTP)        │ │
│ │                                │                      │ │ /var/www          │ │
│ │                                │                      │ │  📁 releases      │ │
│ │                                ├──────────────────────┤ │  📁 shared        │ │
│ │                                │ deploy@db-01:~$ ...  │ │  📄 deploy.sh     │ │
│ │                                │                      │ │                    │ │
│ └───────────────────────────────┴──────────────────────┘ └────────────────────┘ │
│  web-01 · ~/app · 마지막 명령 ✔ 0                         ⌘K 명령/AI · ⌘D 분할  │
└──────────────────────────────────────────────────────────────────────────────────┘
```

- **가운데**: Ghostty 터미널 화면입니다. 분할할 수 있습니다.
- **오른쪽 패널**(⌘⌥I로 열고 닫기)
  - **파일**: 접속 중인 서버의 SFTP 탐색기입니다. 드래그로 업로드·다운로드합니다.
  - **AI** (M5 예정): 명령 추천과 실패 설명을 보여 줍니다.
- **아래 상태 줄**: 호스트, 현재 디렉터리, 마지막 종료 코드, 단축키 안내

### 3) SFTP 탭 (파일 전송 전용)

```text
┌─ 로컬 ─────────────────────────┐  ┌─ web-01 ▾ ─────────────────────┐
│ ~/Downloads                     │  │ /var/www/app                    │
│  📁 release                     │  │  📁 releases                    │
│  📄 build.tar.gz       12 MB    │ ⇄│  📄 .env              1 KB      │
└─────────────────────────────────┘  └─────────────────────────────────┘
 전송 대기열: build.tar.gz → /var/www/app  ████████░░ 80%
```

- 왼쪽은 로컬, 오른쪽은 원격인 두 칸 파일 관리자입니다. 양쪽 사이를 드래그해 전송합니다.
- 오른쪽 위에서 접속할 호스트를 고릅니다.

### 4) ⌘K 명령 팔레트

```text
┌───────────────────────────────────────────────────────┐
│ > 80번 포트를 쓰는 프로세스 찾기                        │
├───────────────────────────────────────────────────────┤
│ ✦ AI   sudo lsof -i :80                    위험도 낮음 │
│ ✦ AI   sudo ss -ltnp 'sport = :80'         위험도 낮음 │
│ ▣ 호스트  web-01 연결                                  │
└───────────────────────────────────────────────────────┘
  Enter: 프롬프트에 입력 (실행 안 함)
```

- 호스트, 메뉴 명령, AI 추천을 한 곳에서 검색합니다.
- AI 추천은 프롬프트에 입력만 하고, 실행은 사용자가 Enter로 합니다.

### 5) 설정 창 (⌘, 또는 왼쪽 메뉴의 "설정") — 구현됨

| 탭 | 항목 |
| --- | --- |
| 터미널 | 글꼴(고정폭 글꼴 목록, 기본 JetBrains Mono), 크기(8~32pt, 미리보기), 커서 모양(막대·블록·밑줄)·깜박임, Option 키를 Alt로 사용(끔·왼쪽·오른쪽·양쪽), Ghostty 전용 terminfo 사용(고급, 기본 끔), `terminal.conf` 직접 편집, 기본값 되돌리기 |
| 테마 | Ghostty에 포함된 테마 819개 + MyTerminal 기본. 검색, 배경·글자색·기본 8색 미리보기 |

- 값을 바꾸면 열려 있는 모든 터미널에 바로 적용됩니다.
- 설정 파일은 아래 순서로 읽고, 뒤의 파일이 앞의 값을 덮어씁니다.

| 순서 | 파일 | 만드는 주체 |
| --- | --- | --- |
| 1 | 앱 번들 `terminal-defaults.conf` | 앱 기본값 |
| 2 | `~/Library/Application Support/MyTerminal/settings.conf` | 설정 창 (직접 고치지 않음) |
| 3 | `~/Library/Application Support/MyTerminal/terminal.conf` | 사용자 직접 편집 (Ghostty 설정 형식) |

- 배경·글자색을 직접 지정하면 테마보다 우선하므로, 기본 설정 파일에는 색을 넣지 않습니다. "MyTerminal 기본" 테마를 고른 경우에만 `settings.conf`에 색을 씁니다.

## 왼쪽 메뉴 범위

| 메뉴 | 내용 | 마일스톤 |
| --- | --- | --- |
| 호스트 | 접속 목록, 그룹, 태그 | M2 |
| 히스토리 | 접속 이력 (날짜·시간, 사용자, 호스트, 저장), 다시 접속 | M3 (구현됨) |
| 설정 | 테마, 폰트, 단축키, AI 키 | M1부터 단계적으로 |
| 포트 포워딩 · Known Hosts · 시리얼 · 동기화 | Termius에 있는 기능 | v0.1 이후 검토 |

> 작업, 키 관리, 스니펫 메뉴는 2026-11-13 사용자 결정으로 제외했습니다. 비밀번호는 호스트 편집 패널에서 Keychain 에 저장합니다.

## 앱 아이콘

- macOS 아이콘 격자(1024 캔버스, 824 둥근 사각형) 위에 남색 그라데이션 바탕, 파란 프롬프트 기호(`>`), 밝은 커서(`_`)
- 앱 화면 색(Theme)과 맞춘 MyTerminal 고유 디자인 (다른 제품의 아이콘·색을 따라 하지 않음)
- `scripts/make-app-icon.swift` 가 크기마다 벡터로 다시 그려 16px 에서도 선명하다. 디자인을 바꾸면 스크립트를 고치고 다시 실행

## 창과 종료

- 창이 하나뿐인 앱이다. 창을 닫으면 앱이 종료된다 (터미널 세션을 화면 없이 뒤에 남기지 않는다)
- 열린 터미널·SFTP 접속이 있으면 종료 전에 **창 위에 붙는 시트**로 확인한다 (닫기 버튼·⌘Q 공통). "종료"일 때만 창을 닫고 끝내며, 취소하면 아무것도 바뀌지 않는다
- 종료할 때 접속 이력의 끝 시각을 남기고, 연결 재사용 ssh 연결을 정리한다

## 화면 기술 구성

- 앱 틀(탭 바, 사이드바, 카드, 패널)은 **SwiftUI**로 만듭니다.
- 터미널 화면은 Ghostty의 **AppKit NSView**를 `NSViewRepresentable`로 감싸 SwiftUI에 넣습니다.
- 위쪽 탭 바는 macOS 기본 창 탭 대신 직접 그립니다. 홈·SFTP 탭을 터미널 탭과 한 줄에 두기 위해서입니다.
