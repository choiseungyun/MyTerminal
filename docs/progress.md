## 지난 단계: M4 SFTP

설계: [features/05-sftp.md](features/05-sftp.md) · 방식: [ADR 0004](decisions/0004-sftp-over-openssh.md) · 완료 기준: 접속 중인 서버 파일을 드래그로 주고받음

- [x] 방식 결정: 시스템 OpenSSH(`ssh -s 호스트 sftp`) 위에 SFTP v3 직접 구현
- [x] SFTP 클라이언트: 목록, 업로드·다운로드(동시 요청), 폴더 만들기, 이름 바꾸기, 삭제 + 테스트 11개 (로컬 sftp-server)
- [x] ssh 연결 재사용(ControlMaster, `/tmp/myterm-<uid>/%C`, 10분 유지) + SFTP 연결, 접속 실패 안내 (테스트 전체 78개)
- [x] 터미널 옆 파일 패널(⌥⌘F): 탐색, Finder 끌어다 놓기 업로드·끌어내기 다운로드, 폴더째 전송, 새 폴더·이름 바꾸기·삭제, 전송 진행률 (테스트 전체 87개)
- [x] SFTP 탭: 이 Mac | 서버 두 칸, 서로 끌어서 전송, 호스트 고르기 (테스트 전체 94개)
- [x] 원격 파일 편집: 편집기로 열고 저장하면 자동 업로드, 바꿔치기 저장 감지, 충돌 판단 (테스트 전체 100개)
