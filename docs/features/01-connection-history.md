# 접속 이력 (히스토리)

마일스톤: M3 (**구현됨**, 사용자 확인 대기) · 이전 계획이던 "작업별 명령어 기록"은 2026-11-13 사용자 결정으로 제외

언제, 이 Mac 의 누가, 어느 서버에, 얼마나 접속했는지를 표로 보여 준다. 명령 내용이나 출력은 기록하지 않는다.

## 화면 (홈 > 히스토리)

| 열 | 내용 |
| --- | --- |
| 날짜 | 접속 날짜, 시작 - 종료 시각. 날짜를 넘기면 `(+2일)`, 열려 있으면 `접속 중`, 앱이 비정상 종료되어 끝을 모르면 `종료 기록 없음` |
| 사용자 | 이 Mac 의 사용자 이름, 컴퓨터 이름 |
| 호스트 | 아이콘(SSH·SFTP), 호스트 이름(저장된 호스트면 지금 이름), `ssh, 사용자` / `sftp, 사용자` |
| 저장 | 저장된 호스트면 채워진 북마크. 빈 북마크를 누르면 그 접속을 **호스트로 저장**하고 같은 접속 기록을 그 호스트에 연결 |

- 더블클릭: 다시 접속 (저장된 호스트면 지금 설정으로, 아니면 기록된 접속 인자로). SFTP 기록은 SFTP 탭으로
- 우클릭: 다시 접속, 호스트로 저장, ssh 명령 복사, 기록 삭제 (여러 개 선택 가능)
- 검색(호스트·사용자·접속 인자), 최근 순 / 오래된 순, 모두 지우기 (저장된 호스트는 지워지지 않음)

## 기록 시점

- 시작: 터미널 SSH 화면이 열릴 때 (새 탭, 분할, 호스트·빠른 연결·이력에서 다시 접속), SFTP 탭에서 서버를 고를 때
- 끝: 화면·탭을 닫을 때, 셸이 끝나 화면이 닫힐 때, SFTP 탭에서 다른 서버로 바꾸거나 닫을 때, 앱을 끝낼 때
- 로컬 터미널은 기록하지 않는다
- 분할 화면은 각각 하나의 접속으로 기록한다 (연결 재사용으로 인증은 한 번)

## 저장

- `myterminal.sqlite` 의 `connection` 테이블 (마이그레이션 v3)
- 호스트를 지워도 기록은 남는다 (기록 당시 이름 표시)
