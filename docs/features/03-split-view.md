# 화면 분할

마일스톤: M1(기본 분할, **구현됨**)

## 기본 분할 (구현됨)

구조만 Ghostty 를 참고하고 직접 구현했습니다. 이유는 [ADR 0002](../decisions/0002-own-split-tree.md)에 있습니다.

| 동작 | 단축키 | 메뉴 |
| --- | --- | --- |
| 좌우로 분할 | ⌘D | 화면 > 좌우로 분할 |
| 위아래로 분할 | ⇧⌘D | 화면 > 위아래로 분할 |
| 다음 / 이전 화면 | ⌘] / ⌘[ | 화면 > 다음 화면 |
| 크기 균등하게 | ⌃⌘= | 화면 > 화면 크기 균등하게 |
| 화면 닫기 | ⌘W | 파일 > 화면 닫기 (마지막 화면이면 탭이 닫힘) |
| 탭 닫기 | ⇧⌘W | 파일 > 탭 닫기 |

- 새 칸에서 **무엇을 열지 고릅니다** (아래 "다른 서버와 분할").
- 화면 사이의 두꺼운 경계 막대(SFTP 와 같은 8pt 막대, 가운데 손잡이, 마우스를 올리면 파랗게)를 끌어 크기를 조절합니다. 더블클릭하면 반반으로 돌아갑니다. 한 화면은 최소 10%입니다.
- 분할되어 있으면 화면마다 **머리줄**(서버 색 점, 이름, 현재 폴더, 닫기)이 붙습니다. 서버마다 색이 정해져 있고(같은 서버는 늘 같은 색, 로컬은 회색), 탭 바의 아이콘도 같은 색입니다.
- 포커스된 화면은 서버 색 테두리와 진한 머리줄, 포커스가 없는 화면은 어둡게 표시합니다. 화면이나 머리줄을 클릭하면 포커스가 옮겨집니다.
- 셸이 끝나면(`exit`) 그 화면이 닫힙니다.

## 다른 서버와 분할 (구현됨)

한 탭 안에서 서로 다른 서버(또는 로컬)를 나란히 쓰기 위한 기능입니다.

### 분할할 때 대상 고르기

⌘D / ⇧⌘D 를 누르면 새 칸에 "이 화면에 열기" 선택 칸이 생깁니다.

| 항목 | 설명 |
| --- | --- |
| 같은 서버 | 나눈 화면과 같은 대상. 검색어 없이 **Enter** 만 누르면 이것 (예전 동작과 같음) |
| 로컬 터미널 | 이 Mac 셸. 로컬 화면에서 나눴으면 그 디렉터리에서 시작 |
| 저장된 호스트 | 검색창에 입력하면 이름·주소·사용자·그룹·태그로 거름 |
| 빠른 연결 | `user@host`, `ssh …` 를 입력하면 바로 접속. 일치하는 호스트가 없을 때도 제안 |

- ↑↓ 로 고르고 Enter, 클릭으로도 엽니다. **Esc**·⌘W·× 는 분할을 취소합니다.
- 고른 대상은 그 칸 자리에서 터미널로 바뀝니다 (배치 유지).

### 탭을 끌어 분할로 합치기

- 탭 바의 탭 이름을 끌어 **다른 탭의 화면 위**에 놓으면 그 화면 옆으로 합쳐집니다. 끄는 동안 탭 이름이 마우스를 따라다닙니다.
- 놓는 위치에서 가장 가까운 가장자리(왼쪽·오른쪽·위·아래)로 나뉘고, 들어갈 절반이 파랗게 미리 보입니다.
- 탭은 **화면에 보이는 다른 탭**에 합쳐집니다. 지금 보고 있는 탭을 끌기 시작하면 바로 전에 보던 탭이 자동으로 보입니다.
- 끄는 탭을 다른 탭 이름 위에 올리면 그 탭으로 전환되므로, 원하는 탭을 골라 놓을 수 있습니다. 놓지 않고 끝내면 처음 보던 탭으로 돌아갑니다.
- 마우스를 따라다니는 이름표가 안내합니다: "화면 가장자리에 놓으면 분할", "합칠 탭 이름 위로 옮기세요", "합칠 다른 탭이 없습니다".
- 구현: 시스템 끌어 놓기(`onDrag`/`onDrop`)는 쓰지 않습니다. 탭 바가 숨긴 제목 표시줄 영역에 있고 화면이 터미널 NSView 라서, 놓는 곳이 우리 처리기로 오지 않을 수 있습니다. 대신 탭 이름 위의 AppKit 화면(`TabDragHandleView`)이 마우스를 직접 따라가고, 칸 위치(workspace 좌표)와 비교해 놓을 곳을 정합니다.
- 창의 자동 이동(`isMovable`)은 꺼 둡니다. 켜 두면 시스템이 탭 바 전체를 "끌면 창 이동" 영역으로 잡아, 탭을 끌 때 창도 같이 움직입니다. 창은 탭 바의 **빈 곳**(신호등 버튼 옆, 탭 목록 뒤, 오른쪽 여백)을 끌 때만 옮겨지고, 빈 곳 더블클릭은 확대/복원입니다.
- **접속을 끊지 않고** 화면(세션)을 그대로 옮깁니다. 끌어 온 탭이 이미 분할되어 있으면 배치째 들어갑니다. 접속 이력도 이어집니다.

### 화면을 새 탭으로 분리

- 화면이 둘 이상일 때 상태 줄 "새 탭으로" 버튼, 또는 메뉴 화면 > 이 화면을 새 탭으로 분리.
- 접속을 유지한 채 원래 탭 바로 뒤의 새 탭으로 옮깁니다.

## 추가 예정

- **배치 저장·복원**: 분할 배치와 각 화면의 접속을 저장했다가 복원 (v0.1 이후 검토)
- **동시 입력(브로드캐스트)**: 여러 화면에 같은 입력을 보냅니다. 여러 서버 일괄 작업용이며, 켜져 있을 때 화면에 눈에 띄게 표시합니다.
- **방향키 화면 이동**, **화면 확대(zoom)**
