# 쉬운 SFTP

마일스톤: M4 (**구현 완료**, 사용자 확인 대기) · 방식: [ADR 0004](../decisions/0004-sftp-over-openssh.md)

## 구조

```text
터미널 화면 (ssh … user@host) ─┐
                               ├─ 연결 재사용 (ControlMaster, /tmp/myterm-<uid>/%C)
파일 패널 (ssh -s … sftp) ─────┘    → 한 번 인증한 연결을 함께 쓴다
        │
        └─ SFTPClient (SFTP v3, Swift 로 직접 구현)
```

- 접속은 시스템 OpenSSH 가 하므로 `~/.ssh/config`, ssh-agent, 키, 점프 호스트, 저장된 비밀번호 자동 입력이 터미널과 똑같이 동작한다.
- 터미널이 같은 서버에 이미 접속해 있으면 파일 패널은 **인증 없이 바로** 열린다 (비밀번호·OTP 재입력 없음).
- 터미널 없이 처음 접속하는 경우 키·에이전트·저장된 비밀번호로 인증한다. 호스트 키 확인처럼 직접 답해야 하는 질문이 있으면 "먼저 터미널로 접속하세요" 안내를 보여 준다.

## 터미널 옆 파일 패널 (구현됨)

- 열기: 탭 바 오른쪽 **SFTP** 버튼(열려 있으면 파란색), 상태 줄 오른쪽 **파일** 버튼, **⌥⌘F** (화면 메뉴). 포커스된 SSH 화면의 서버 파일을 보여 준다
- 호스트 카드 우클릭·편집 패널 `…` 메뉴 → **연결하고 파일 보기 (SFTP)**: 접속과 동시에 파일 패널을 연다
- **폭 조절**: 터미널과 패널 사이 경계 막대(8pt, 가운데 손잡이, 마우스를 올리면 파랗게)를 끌어서 (260pt ~ 창의 75%). 폭은 기억되고, 막대 더블클릭으로 기본 폭(340pt)
- 이름 우선: 패널이 좁으면(400pt 미만) 수정 시각을 숨긴다. 마우스를 올리면 전체 이름·크기·시각·경로
- 처음 위치: 원격 홈 폴더. 경로 표시줄의 각 조각을 눌러 상위로 이동, "경로로 이동…"으로 직접 입력
- 목록: 폴더 먼저, 이름순. 크기·수정 시각. 숨김 파일(`.`) 보기 전환
- **업로드**: Finder 에서 파일·폴더를 패널에 끌어다 놓기, 또는 업로드 버튼. 폴더는 안의 내용까지
- **다운로드**: 파일을 Finder 로 끌어내기, 파일 더블클릭(다운로드 폴더로), 우클릭 → 다른 위치에 받기. 폴더는 안의 내용까지. 같은 이름이 있으면 " 2" 를 붙인다
- 우클릭: 열기, 다운로드, 이름 바꾸기, 경로 복사, 삭제(폴더는 안의 내용까지, 확인 후)
- 전송 목록: 진행률, 완료 크기, 실패 이유, 받은 파일 Finder 에서 보기
- 오류(권한 없음 등)는 패널 위에 띠로 보여 주고 연결은 유지한다. 연결이 끊기면 "다시 연결" 버튼

## SFTP 탭 (구현됨)

- 위쪽 **SFTP** 탭. 왼쪽 **이 Mac**, 오른쪽 **서버**. 기본 반반, 두 칸 사이 경계 막대를 끌어 조절(비율 기억, 더블클릭하면 반반). 오른쪽 내용이 바뀌어도 비율 유지
- 오른쪽 칸은 처음에 호스트 고르기 (저장된 호스트, 최근 빠른 연결, 검색, `user@host` 입력). 닫기(→|) 하면 다시 고르기
- 칸 사이로 끌어서 전송: 왼쪽 → 오른쪽 업로드, 오른쪽 → 왼쪽 다운로드. Finder 와도 주고받을 수 있다
- 원격 파일 더블클릭·우클릭 "로컬 칸으로 받기" → 왼쪽 칸의 현재 폴더로 받는다
- 왼쪽 칸: 홈·다운로드 바로가기, 새 폴더, 이름 바꾸기, 휴지통으로 이동(되돌릴 수 있음), Finder 에서 열기, "원격으로 올리기"
- 호스트 카드 우클릭·편집 패널 `…` → **SFTP 탭에서 열기**

## 원격 파일 편집 (구현됨)

- 원격 파일 우클릭 → **편집 (저장하면 서버에 올리기)** 또는 **다음 앱으로 편집…**
- 받은 사본을 기본 편집기(또는 고른 앱)로 연다. 사본 위치: `~/Library/Caches/MyTerminal/Edit/` (원래 파일 이름 유지)
- 편집기에서 **저장하면 자동으로 올린다**: 연달아 저장하면 0.4초 동안 모아 한 번, 내용이 같으면 올리지 않음 (SHA-256 비교)
- "새 파일에 쓰고 바꿔치기" 방식으로 저장하는 편집기도 감지한다
- 같은 파일의 업로드는 한 번에 하나씩. 올리는 동안 또 저장하면 끝난 뒤 한 번 더 올린다
- **충돌**: 받은 뒤 서버 파일의 수정 시각이 바뀌었으면 덮어쓰지 않고 표시 → "내 것으로 덮어쓰기" / "서버 버전 받기"
- 패널의 **편집 중** 목록: 마지막으로 올린 시각, 올리는 중, 충돌·오류, 다시 열기, 편집 끝내기(사본 삭제)
- 앱을 다시 시작하면 지난 실행의 사본은 지운다 (감시가 끊겨 동기화되지 않으므로)
- 한계: SFTP v3 의 수정 시각은 초 단위라, 같은 초 안에 서버에서 바뀐 것은 충돌로 잡지 못할 수 있다

## 성능

- 32KB 조각, 요청 16개를 동시에 보낸다 (지연이 큰 연결에서도 속도 확보)
