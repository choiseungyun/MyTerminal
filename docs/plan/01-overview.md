# 1. 개요

MyTerminal은 Ghostty의 터미널 엔진(libghostty) 위에 직접 설계한 UI를 얹은 macOS 터미널입니다. 약 17주(4~5개월) 뒤 v0.1을 오픈소스로 공개하는 것이 목표입니다.

## 핵심 기능

기존 터미널(iTerm2, Ghostty)에 없는 다섯 가지 기능을 핵심으로 합니다.

1. **접속 이력**: 언제, 어느 서버에, 얼마나 접속했는지 기록하고 다시 접속·호스트로 저장을 지원합니다. (작업별 명령 기록은 2026-11-13 제외)
2. **접속 목록**: SSH 서버 프로파일을 저장하고 클릭 한 번으로 접속합니다.
3. **화면 분할**: 가로·세로 분할, 배치 저장, 여러 화면 동시 입력을 지원합니다.
4. **AI 명령 추천**: 자연어로 원하는 작업을 말하면 명령을 제안합니다. 실행은 항상 사용자가 직접 합니다.
5. **쉬운 SFTP**: 접속 중인 서버의 파일을 옆 패널에서 드래그 앤 드롭으로 주고받습니다.

기능별 상세 설계는 [features/](../features/)에 있습니다.
