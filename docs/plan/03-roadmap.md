# 3. 마일스톤과 일정

1인 기준 약 17주(4~5개월) 뒤 v0.1을 공개합니다. 시작일이 정해지면 주차를 날짜로 바꿉니다.

| 단계 | 내용 | 기간 | 누적 | 완료 기준 |
| --- | --- | --- | --- | --- |
| **M0** 환경과 분석 | Xcode, Zig 설치. Ghostty 원본 앱 빌드와 구조 분석, xcframework 빌드 | 1주 | 1주 | 원본 Ghostty가 내 Mac에서 빌드되어 실행됨 |
| **M1** 내 앱 골격 | Xcode 프로젝트 생성, 앱 틀(탭 바, 왼쪽 메뉴, 홈 화면), GhosttyKit 연결, 터미널 탭, 화면 분할(자체 구현), 한글 입력 검증 | 3주 | 4주 | 내 앱에서 zsh, vim, tmux가 정상 동작 |
| **M2** 접속 목록 | 호스트 카드, 검색 연결, 프로파일 CRUD, ssh config 가져오기, 비밀번호 Keychain 저장 | 2주 | 6주 | 클릭 한 번으로 서버 접속 |
| **M3** 접속 이력 | 접속 시작·끝 기록, 히스토리 표, 다시 접속, 호스트로 저장 | 1주 | 7주 | 언제 어느 서버에 접속했는지 보고 다시 접속 |
| **M4** SFTP | PoC로 라이브러리 결정, 탐색기 패널, 전송, 원격 편집 | 3~4주 | 13주 | 접속 중인 서버 파일을 드래그로 주고받음 |
| **M5** AI 도우미 | API 연결, ⌘K 팔레트, 실패 설명, SSH 접속 실패 진단, 민감정보 가림 | 2주 | 15주 | 자연어로 명령 추천을 받아 입력 |
| **M6** 공개 준비 (v0.1) | README, LICENSE, CONTRIBUTING, GitHub Actions CI, 서명과 공증, DMG | 2주 | 17주 | GitHub Release로 누구나 설치 가능 |

> 2026-11-13: 원래 M3(작업별 명령 기록)는 사용자 결정으로 제외하고, 키 관리·스니펫 메뉴도 제외. M3 는 접속 이력으로 바꿈. AI 추천(M5)은 명령 기록 대신 현재 화면 맥락(디렉터리, 선택한 출력)을 쓴다.

## 순서를 이렇게 정한 이유

- 접속 이력(M3)과 SFTP(M4)는 모두 접속 모델 위에서 동작하므로 접속 목록(M2)을 먼저 합니다.
- 일정이 밀리면 M4, M5의 범위를 줄여 v0.1을 먼저 공개하고 나머지는 v0.2로 넘깁니다.
